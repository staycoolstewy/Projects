# Instructions for Claude – Colburn Avenue Tendering

This folder is the single source of memory for the Colburn Avenue tender. Work and
chats happen across many files and systems, so:

1. **At the start of every session**, read `README.md` (project facts, decisions,
   open items) and the latest entries in `LOG.md` before doing anything else.
2. **When facts change** (dates, contacts, scope, where a file lives), update
   `README.md` straight away.
3. **At the end of every session**, add a dated entry to the top of `LOG.md`
   summarising what was done, decided and what's next.
4. When information comes from another system (email, calendar, Smartsheet, etc.),
   record a short note and a pointer to where it lives, not just the conclusion.
5. Commit and push changes so the memory survives between sessions.
